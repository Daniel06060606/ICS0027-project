# Secure Password Manager

## Project scope

This project is a web-based password manager.
Users will be able to register, log in and manage their saved passwords.

## Planned features

- User registration
- User login
- Add saved passwords
- View saved passwords
- Edit saved passwords
- Delete saved passwords
- User sessions

## Planned routes

- /register
- /login
- /logout
- /passwords

## Technologies

- HTML / CSS / JavaScript
- Node.js
- MySQL
- Node.js crypto
- HTTPS
