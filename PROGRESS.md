# Checkpoint 2

Registration, login and logout are working. Users can add, view, edit and delete password entries. Files can be uploaded, encrypted on the server and downloaded after decryption. The app uses Node.js and MySQL with a plain HTML, CSS and JavaScript interface. Login passwords are hashed with scrypt, and saved data is encrypted with AES-256-GCM using a key derived from the master password. Sessions use secure cookies, expire after 30 minutes of inactivity and are removed on logout. Each user can only access their own data. The development setup runs over HTTPS and can be started with Docker Compose. Further work is security testing and fixing any issues found before the final checkpoint.
